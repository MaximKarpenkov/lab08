# Лабораторная работа 8. Словари, множества и кортежи

## Как запустить
1. Демонстрация: `python collections_lab.py`
2. Проверки: `python test_collections.py`

---

## Структура файлов
- `collections_lab.py` — модуль с функциями.
- `test_collections.py` — автотесты через `assert`.

---

## Проверки

### 1. Частоты слов
| Ввод | Ожидаемый | Факт |
|---|---|---|
| `Python, python! SQL` | `{"python": 2, "sql": 1}` | Совпадает |
| `!!!` | `{}` | Совпадает |
| `` (пусто) | `{}` | Совпадает |

### 2. Темы (множества)
| first | second | common | all |
|---|---|---|---|
| `["python","sql","python"]` | `["sql","git"]` | `["sql"]` | `["git","python","sql"]` |
| `[]` | `["python","sql"]` | `[]` | `["python","sql"]` |

### 3. Запись и пара
После изменения: `{"title": "Python", "hours": 6, "completed": False}`.
Распаковка кортежа: `name = "Python"`, `hours = 6`.

### 4. Вариант 1 (сводка по категориям)
| Действие | Ожидаемый | Факт |
|---|---|---|
| `totals_by_category(records)` | `{"основное": 7, "дополнительное": 2}` | Совпадает |
| `titles_in_category(records, "основное")` | `["A", "C"]` | Совпадает |
| `titles_in_category(records, "нет такой")` | `[]` | Совпадает |
| `totals_by_category([])` | `{}` | Совпадает |

Исходные записи после вызовов **не изменились** (сравнение с `[r.copy() for r in records]`).

### 5. Дополнительно
`sorted_pairs_by_total(records)` → `[("основное", 7), ("дополнительное", 2)]`.
